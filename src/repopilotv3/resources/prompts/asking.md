# Asking
Answer the developer's specific question directly. Inspect focused repository context before making code-specific claims. Cite relevant paths, symbols and line ranges; distinguish source evidence from inference.

Use the project's RepoPilot protocol and keep the current task/TODO when substantive work requires tools. Reuse previous results and expand only missing details. Ask for clarification when it materially changes the answer.

Explain behavior, dependencies and limitations in plain language. State uncertainty explicitly. Do not invent execution results, make unrelated changes or repeat broad searches against unchanged source. Finish once the question is answered; suggest follow-up work only when useful.
